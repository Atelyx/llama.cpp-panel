# llama.cpp 启动面板

把本机 llama.cpp 服务（`llama-server`）接进 Atelyx 的**工作台插件**（`panel` 类型）：递归扫描模型目录列出 `.gguf` 模型，选模型、调启动参数、一键启停，实时看运行状态、连接状态与进程日志。

> **要求：Atelyx 0.5.0 及以上**（插件包格式：`package.json` + 入口默认导出 `apply(ctx)`）。

## 用法

在设置页选 **llama-server 所在文件夹**（里面放 `llama-server`，Windows 为 `llama-server.exe`；启动时按平台名在里面查找）与**模型目录**，然后在「llama.cpp」面板里：

1. 左栏按文件夹列出扫描到的模型，同一文件夹的多个量化收在一个条目里（行内标注量化数、投影数与量化体积合计）。
2. 选中文件夹后，右侧表单给出启动参数：量化文件、视觉投影、GPU 层数、上下文长度、线程数、并行槽位、KV 缓存 K 量化、载入模式、Flash Attention / Jinja / 隐藏 WebUI、附加参数。参数**按模型文件夹持久化**，换模型即带出上次的值。
3. 点「启动」——进入启动中，服务接口就绪后转为运行中；日志区实时显示进程输出（尾部 300 行，按级别着色，可清屏），标题行显示本次执行的命令。
4. 点「停止」结束整棵进程树。

模型目录里以 `mmproj` 开头的文件识别为视觉投影，选中模型时自动挂载同目录的那一个。

## 连接与状态

- **运行状态**：运行中 / 启动中 / 已停止 / 启动失败——启动失败会弹宿主通知，带退出码与最后一条错误输出。
- **连接状态**：插件直连 `http://监听地址:端口` 探测（依次试 `/api/models`、`/api/version`、`/`），活跃期定时轮询，服务由你自己起的也能看到「已连接」。
- 监听地址填 `0.0.0.0` 时局域网设备可访问 API/WebUI，插件自身探测仍走 `127.0.0.1`。

## 进程

设置里可选**托管**（插件启停；停止会结束整棵进程树，含包装层 `cmd.exe`/`sh`）或**外部**（进程归你管，插件只探测连接）。插件停用、卸载或应用退出时，Atelyx 会一并结束它启动的进程。

## 权限

| 声明 | 用途 |
| --- | --- |
| `shell` | 启动与停止 llama-server 进程（可改为「外部」不托管） |
| `state` | 保存插件设置：llama-server 文件夹、监听地址与端口、模型目录、进程模式、各模型的启动参数 |
| `fs` | 读取你指定的模型目录与 llama-server 文件夹，列出其中的 `*.gguf` 与可执行文件 |
| `app` | 读取宿主平台，决定启动命令写法（Windows `cmd.exe` / Unix `sh`） |
| `notification` / `dialog` | 启停与连接结果提示、选择 llama-server 文件夹与模型目录 |

探测请求只发向你配置的地址，插件不做任何联网上传。
