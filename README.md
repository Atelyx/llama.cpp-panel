# llama.cpp 启动面板

把本机 `llama-server` 接进 Atelyx（`panel` 类型插件）：检索并下载 gguf 模型（可选镜像站），扫描模型目录选模型、调启动参数、一键启停，并实时查看运行状态、连接状态与进程日志。

> 需要 Atelyx 0.5.0 及以上。

插件提供三个视图——**模型库 / 已装模型 / 日志**，在面板的「添加视图」里逐个添加，可拖动或拆到不同面板。

## 模型库与下载

「模型库」按关键词检索 HuggingFace 模型（可按下载量/点赞/最近更新排序），进入仓库可看 `.gguf` 文件清单（含体积）与模型卡简介，点「下载」即开始。

- **镜像站**：内置 `hf-mirror.com`（国内镜像）与 `huggingface.co`（官方），检索与下载都走所选站点。
- **落盘位置**：`模型目录/发布者/模型名/`（首次下载时创建）；文件名取仓库内的文件名，仓库内的子目录会被压平。同一仓库的量化与视觉投影因此同处一个文件夹，模型列表可自动配上 mmproj。
- **断点续传**：先写 `<文件名>.part`，完成后改名 `.gguf`——模型列表不会出现半截文件；中断后再点下载会从断点继续。
- **重复检测**：同一模型文件夹内已有同名文件时不会重下，并提示其位置。
- **进度**：显示已下/总量、百分比与速度，可随时暂停（保留已下部分）或继续；服务端未给出体积时显示「未知大小」，不影响下载。下载不设大小或时长上限。
- **门控模型**需先在官网同意条款，本插件无法代下，请用浏览器下载后放入模型目录。
- 下载经系统 `curl` 执行（Windows 10 1803+ 与主流 Linux 自带）；缺失时给出安装提示。

## 已装模型与启动

先在设置页选 **llama-server 所在文件夹**（启动时按平台名在其中查找可执行文件）与**模型目录**，然后在「已装模型」视图：

1. 按文件夹列出扫描到的模型，同一文件夹的多个量化合并为一个条目（标注量化数、投影数与体积合计）。
2. 选中文件夹后在右侧设置启动参数：量化文件、视觉投影、GPU 层数、上下文长度、线程数、并行槽位、KV 缓存 K 量化、载入模式、Flash Attention / Jinja / 隐藏 WebUI、附加参数。参数**按模型文件夹持久化**，换模型即带出上次的值。
3. 顶部「启动」按当前模型与参数拉起服务，接口就绪后转为运行中；「日志」视图实时显示进程输出（尾部 300 行，按级别着色，可清屏），标题行显示本次执行的命令。
4. 顶部「停止」结束整棵进程树。

顶部状态点同时给出**连接状态**（已连接 / 未连接）与**运行状态**（运行中 / 启动中 / 已停止 / 启动失败）。

模型目录中文件名含 `mmproj` 的识别为视觉投影，选中模型时自动挂载同目录的那一个。

## 连接与状态

- **运行状态**：运行中 / 启动中 / 已停止 / 启动失败；启动失败会弹宿主通知，附退出码与最后一条错误输出。
- **连接状态**：插件直连 `http://监听地址:端口` 探测（依次试 `/api/models`、`/api/version`、`/`），活跃期定时轮询——服务即使由你自行启动也能看到「已连接」。
- 监听地址填 `0.0.0.0` 时局域网设备可访问 API/WebUI；插件自身探测仍走 `127.0.0.1`。

## 进程

设置里可选**托管**（由插件启停，停止会结束整棵进程树，含 `cmd.exe`/`sh` 包装层）或**外部**（进程归你管，插件只探测连接）。插件停用、卸载或应用退出时，Atelyx 会一并结束它启动的进程。

## 权限

| 声明 | 用途 |
| --- | --- |
| `shell` | 启停 llama-server；模型检索与下载经系统 `curl` 执行 |
| `state` | 保存设置：llama-server 文件夹、监听地址与端口、模型目录、下载镜像站、进程模式、各模型的启动参数 |
| `fs` | 读取所选模型目录与 llama-server 文件夹；下载时在模型目录写入 gguf 与临时文件；同名文件不会覆盖，会先检出并提示改用带序号的名字 |
| `app` | 读取宿主平台，决定启动命令写法（Windows `cmd.exe` / Unix `sh`） |
| `notification` / `dialog` | 启停与连接结果提示；选择 llama-server 文件夹与模型目录 |

网络访问仅两处：探测请求发往你配置的 `监听地址:端口`（本机或局域网），模型检索与下载发往所选镜像站（默认 `hf-mirror.com`，请求内容只有仓库名与文件名）；其余不做任何联网上传。
